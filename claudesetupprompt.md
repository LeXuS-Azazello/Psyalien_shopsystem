# Промпт для настройки Claude Code сотруднику

Скопировать всё, что ниже разделителя, в первое сообщение новой сессии Claude Code.
Запускать из любой папки — настройка глобальная.

---

Настрой мою глобальную конфигурацию Claude Code: MCP-серверы, скиллы, субагенты и
правила. Ниже точный список и жёсткие требования к порядку работы.

## Требования (соблюдать все)

1. **Сначала аудит, потом план, потом изменения.** Покажи, что уже есть в `~/.claude`
   и `~/.claude.json`, покажи конфликты с тем, что собираешься ставить, и дождись
   моего подтверждения плана. Не начинай менять файлы до этого.
2. **Сделай полный бэкап `~/.claude`** перед первым изменением. Клади архив **вне**
   `~/.claude` — например в `~/.claude-backup/` — иначе он попадёт сам в себя.
   Проверь архив на целостность и покажи команду отката.
3. **Ничего не перезаписывай вслепую.** Существующий `~/.claude/CLAUDE.md`, если он
   есть, дополняй, а не заменяй. Существующие скиллы не трогай.
4. **Ничего не удаляй** без моего явного подтверждения.
5. В конце покажи итоговое дерево `~/.claude/` и проверь, что всё видно Claude Code.

## 1. MCP-серверы

Ставить в user scope (`-s user`), чтобы работали во всех проектах:

```
claude mcp add -s user playwright -- npx -y @playwright/mcp@latest
claude mcp add -s user context7 -- npx -y @upstash/context7-mcp@latest
claude mcp add -s user sequential-thinking -- npx -y @modelcontextprotocol/server-sequential-thinking
```

После playwright обязательно докачай браузер, иначе сервер поднимется, но упадёт при
первом открытии страницы:

```
npx -y playwright@latest install chromium
```

Проверь здоровье всех трёх: `claude mcp list` — должно быть три `✔ Connected`.

**Perplexity и Firecrawl требуют API-ключ.** Ключи ты не вводишь — не проси их у меня
и не вставляй в конфиг сам. Вместо этого выдай мне две готовые команды с плейсхолдером,
чтобы я подставил ключ и выполнил сам:

```
claude mcp add -s user perplexity --env PERPLEXITY_API_KEY=КЛЮЧ -- npx -y server-perplexity-ask
claude mcp add -s user firecrawl --env FIRECRAWL_API_KEY=КЛЮЧ -- npx -y firecrawl-mcp
```

Скажи, где эти ключи берутся и что оба сервиса платные.

## 2. Graphify

CLI ставится из PyPI (пакет `graphifyy`), не из исходников. Нужен `uv`:

```
brew install uv          # если нет brew — curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install graphifyy
graphify install --platform claude
```

Учти: `graphify install` сам дописывает блок в `~/.claude/CLAUDE.md`. Если ты потом
будешь добавлять туда что-то ещё — этот блок должен остаться дословно.

## 3. Скиллы из двух репозиториев

- https://github.com/haraldalder-vibemogger/mcp-diet — скиллы `mcp-to-code` и `skill-harvester`
- https://github.com/haraldalder-vibemogger/vibe-audit — скилл `vibe-audit`

Склонируй во временную папку, прочитай README, скопируй папки скиллов в
`~/.claude/skills/`. Это сторонний код — перед установкой просмотри питон-скрипты
внутри на предмет сетевых вызовов и разрушительных операций и скажи, что нашёл.

## 4. Пакет claude.md — интегрировать, а не заменять

https://github.com/haraldalder-vibemogger/claude.md

Это **проектный** пакет, и в глобальную конфигурацию он в лоб не переносится. Разложи так:

- `.claude/agents/*` (шесть субагентов) → `~/.claude/agents/`
- `.claude/rules/*` (три правила) → `~/.claude/rules/`
- `.claude/hooks/block-secrets.sh` → `~/.claude/hooks/`, **но в settings.json не подключать.**
  Он блокирует любую запись со словами `api_key`/`secret`/`password` и будет ложно
  срабатывать на `.env.example`, `docker-compose.yml` и документацию. Пусть лежит
  готовым к включению.
- весь пакет как есть, нетронутым → `~/.claude/templates/claude-md-pack/`,
  чтобы разворачивать в конкретные репозитории вместе с `docs/stream/`
- ядро `CLAUDE.md` → **дописать** в конец `~/.claude/CLAUDE.md`

При переносе ядра и агентов обязательно сделай три правки, иначе конфигурация будет
битой:

1. **Пути.** В агентах и правилах ссылки вида `.claude/rules/bayes.md` относительные —
   глобально они разрешатся в текущий рабочий проект, где этих файлов нет. Перепиши на
   `~/.claude/rules/...`.
2. **`docs/stream/` не переносится в глобал.** Это память конкретного репозитория.
   Блок `## Memory protocol` в глобальное ядро не клади, а к оставшимся упоминаниям
   `docs/stream/*` добавь пометку, что шаг пропускается, если в проекте такой папки нет.
3. **Блок `## Project` с плейсхолдерами `[fill in]` в глобал не клади** — он про
   конкретный репозиторий.

И добавь от себя ограничитель к режиму LOOP: он для реализации, а не для однострочных
правок, вопросов и чтения. Без этого «каждая задача начинается с бинарно проверяемой
цели» распространится и на «покажи содержимое файла».

Предупреди меня отдельно, что глобальное ядро включает режим LOOP и обязательную
вертикаль верификаторов **во всех проектах**, включая мелкие задачи, и спроси, хочу ли
я полное ядро или только поведенческие правила Карпатого плюс hard rules.

## 5. Проверка и отчёт

- `claude mcp list` — все серверы Connected
- у каждого скилла и агента валидный frontmatter с `name` и `description`
- `settings.json` — валидный JSON; покажи, изменился он или нет
- прогони `python3 ~/.claude/skills/vibe-audit/scripts/audit.py <любой мой проект>`,
  чтобы убедиться, что скилл работает. Запускай из отдельной папки: отчёт пишется в
  текущую директорию
- покажи итоговое дерево `~/.claude/`
- напиши файл `~/.claude/INSTALLED.md`: что откуда пришло, что изменено относительно
  оригиналов, путь к бэкапу и команда отката

Честно скажи, что проверить не смог. В частности: «скиллы видны Claude Code»
детерминированно проверяется только расположением и frontmatter — живой запрос через
`claude -p` из сессии может не пройти авторизацию.

## 6. Заодно по моим репозиториям

Проверь мои рабочие проекты на одну конкретную вещь: **Claude Code читает `CLAUDE.md` и
не читает `AGENTS.md`**. Если в репозитории есть только `AGENTS.md`, его инструкции в
сессию не попадают вообще. Для каждого такого репозитория предложи `CLAUDE.md` с
импортом `@AGENTS.md`.

Но сначала прочитай сам `AGENTS.md` и сверь с кодом. Если он устарел и противоречит
тому, что реально в репозитории, — не импортируй его, а скажи мне об этом: два
конфликтующих набора инструкций хуже одного отсутствующего.
