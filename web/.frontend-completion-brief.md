# Finish the PsyAlien ShopSystem frontend

## Objective and audience
Finish the in-progress React/TypeScript inventory dashboard in this directory
for shop-floor operators and local system administrators. The working tree
already contains a substantial UI refactor and new catalog/support screens;
continue those changes instead of replacing the application or reverting work.

## Direction
Preserve and complete the current quiet, editorial operations-console style:
warm off-white surfaces, restrained deep-green accents, crisp borders, generous
spacing, and compact monospace metadata. Keep the existing system sans-serif /
monospace typography pairing and CSS variable palette in `src/ui/styles.css`.

## Content and behavior
Keep the current Overview, Products, Inventory, Readers & integrations,
Settings, and User guide screens and their existing API wiring. Prioritize a
coherent responsive layout, readable tables and forms, accessible keyboard
focus and labels, and clear loading, empty, success, and error states. Preserve
the established safety semantics: RFID reads are observations, stock changes
use the movement ledger, and tag assignment does not write to physical tags.
Do not introduce new backend behavior or expose secrets.

## Output and constraints
Edit the existing frontend files in this project. Do not create a standalone
mockup. No imagery is needed. **Do not open a browser, start a browser/server,
run Playwright, or take screenshots**; finish and validate in blind/static mode
using the existing project checks only. Avoid changing unrelated backend or
firmware files.
